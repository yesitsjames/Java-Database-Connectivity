JDBC Project

This JDBC project showcases the Liverpool team, consisting of tables and databases. Made to be from the perspective from Arne Slot the manager. He will need this database for managing player details and game statistics for his team to accurately organize this team into the most optimal one in the league.
This application can be used to store, update and analyze player details and their performance statistics effectively.
Features:
CRUD Operations
-Add
-Updates
-Delete
- View Player Details
- View Player Statistics

Uses a relational database (players and statistics) 
Exports data with positions and statistics. 

Information:
Consists of two tables:
Player Details: Name, position, age, nationality, contract duration, etc,
Game Statistics: Appearances, goals, assists, yellow cards, and red cards.

Unique player positions.
Total players grouped by position.
